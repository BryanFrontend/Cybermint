## What can be developed today

This repository holds documentation and artwork. There is no application, no `package.json`, no lockfile and no build. Work that fits here:

- refining product and technical design in `docs/`
- editing and regenerating artwork in `docs/assets/`
- recording decisions as they are made (venue, escrow program, custody, `a_bps`)

## Documentation checks

Requirements: Node.js 18 or newer. No install step.

```bash
node scripts/check-docs.mjs
```

What it checks:

| Check | Fails when |
| :-- | :-- |
| Links and images | A relative link, `src` or `href` in any Markdown file points at a missing file |
| Anchors | A `#fragment` does not match a heading slug in the target Markdown file |
| SVG safety | An SVG contains `<script>`, `<foreignObject>`, an event handler attribute, CSS `@import`, a remote `url()`, or any `href` that is not an internal `#id` |
| SVG accessibility | An SVG has no `<title>` |
| House style | Markdown or SVG text contains an em dash |
| Environment template | `.env.example` contains a secret-like variable name or a value shaped like an encoded private key |

External URLs are not fetched. The script exits with status 1 and lists every problem when anything fails.

## Artwork pipeline

All SVGs in `docs/assets/` are generated by `tools/artwork/build_assets.py`. Text is converted to outlines so every viewer sees the same typography regardless of installed fonts, which means outlined SVGs should not be edited by hand. Change the generator and regenerate.

| File | Role |
| :-- | :-- |
| `tools/artwork/build_assets.py` | Draws every asset: hero, status strip, dividers, diagrams, logo |
| `tools/artwork/svgkit.py` | Palette, text shaping and outlining, primitives, overflow checks |
| `tools/artwork/logo-layers.json` | Vector paths traced from `docs/assets/cybermint-logo.png` |
| `tools/artwork/trace_logo.py` | Re-traces the logo PNG into `logo-layers.json` |
| `tools/artwork/requirements.txt` | Python packages |

Requirements: Python 3.10 or newer, the packages in `requirements.txt`, and these fonts installed locally:

- Inter and Inter Display (OTF), default location `/usr/share/fonts/opentype/inter`, override with `CYBERMINT_INTER_DIR`
- DejaVu Sans Mono (TTF), default location `/usr/share/fonts/truetype/dejavu`, override with `CYBERMINT_DEJAVU_DIR`

```bash
python3 -m pip install -r tools/artwork/requirements.txt

# Regenerate everything
python3 tools/artwork/build_assets.py docs/assets tools/artwork/logo-layers.json

# Regenerate selected assets: logo hero status dividers fee shield lifecycle arch
python3 tools/artwork/build_assets.py docs/assets tools/artwork/logo-layers.json fee shield

# Re-trace the logo after replacing the PNG (needs potracer, numpy, scipy, pillow)
python3 tools/artwork/trace_logo.py docs/assets/cybermint-logo.png tools/artwork/logo-layers.json
```

The generator asserts that labels fit their boxes and stops with an `overflow:` error naming the text when one does not. Shorten the copy or widen the box.

PNG files are not generated by the script: `social-preview.png` is a 1280 by 640 render of `hero.svg` (suitable for the repository's social preview setting), and `film-poster.png` is a frame from the brand film.

### Visual system

| Token | Hex | Use |
| :-- | :-- | :-- |
| Near black | `#0C0C0E` | Panels, outlines |
| Panel | `#141518`, `#1B1D21` | Cards on dark |
| Rule | `#2C2F34` | Hairlines and borders |
| Electric mint | `#2AF7BC` | Primary accent, flow arrows, verified state |
| Deep mint | `#038559` | Hard offset shadows |
| Pale mint | `#BBF9E6` | Secondary text, pending state |
| Muted gray | `#8A9096` | Body text on dark, dividers |
| Warm white | `#F4F1EA` | Headlines, light cards |

Rules: hard offset shadows rather than blur; outlines in near black; every state is labelled in text, never by color alone; dark panels carry their own background so they read on both GitHub themes; dividers use mid gray rails so they read on light and dark.

## Writing rules

These apply to everything in this repository:

- Every capability claim carries a status: implemented and verified, implemented but not verified, planned, or external integration required.
- No em dashes, no emojis.
- No claims of audits, deployments, partnerships, performance or production readiness without linkable evidence.
- Amounts in technical examples are integers: lamports for SOL, base units for tokens. Illustrative values are labelled as illustrative.
- Do not guess addresses. TRUMP mint, treasury, escrow program and production domain are published by maintainers or left blank.

## Configuration

No code reads environment variables yet. `.env.example` lists proposed browser safe variables with empty values. Copy it to `.env` only when an application exists; `.env` is ignored by git.

Anything bundled into browser code is public. A value is browser safe only when exposing it to every visitor is harmless.

## Server only configuration

These are proposed names for values that must never enter a browser bundle or `.env.example`. They belong in the deployment platform's secret store or a key management system.

| Name (proposed) | Purpose |
| :-- | :-- |
| `CYBERMINT_RPC_URL_PRIVATE` | RPC endpoint that embeds an API key |
| `CYBERMINT_METADATA_STORAGE_CREDENTIAL` | Write access to metadata storage |
| `CYBERMINT_PURCHASE_SIGNER_REF` | Reference to the purchase signer in a key management system, never the key itself |
| `CYBERMINT_FEE_COLLECTOR_SIGNER_REF` | Reference to the fee collection authority, if the design needs one |
| `CYBERMINT_INDEXER_DATABASE_URL` | Ledger database connection |
